# 🌦️ Weather App

A simple and responsive Weather App built using **HTML, CSS, and JavaScript**. The application allows users to search for any city and view real-time weather information through API integration. It provides an intuitive interface for checking current weather conditions quickly and efficiently.

## 🚀 Features

* Search weather by city name
* Display current temperature
* Show weather conditions
* Display humidity levels
* Show wind speed information
* Responsive and user-friendly design
* Real-time weather data fetching

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📸 Preview

Users can enter a city name and instantly view weather details, including temperature, humidity, wind speed, and weather conditions.

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder.

3. Launch `index.html` in your browser.
